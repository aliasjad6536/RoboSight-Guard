# RoboSight Guard: AI-Powered Workplace Safety & Collision Avoidance System

## Abstract
RoboSight Guard is an optimized computer vision-based safety system designed for industrial accident mitigation by processing real-time CCTV footage, calculating spatial Euclidean proximity between workers and machinery, and triggering emergency protocols.

## Methodology & Architecture
The system integrates YOLOv8 with ByteTrack for persistent entity tracking and Euclidean distance evaluation to assess danger zone radiuses.
